# Ghibli Meadow

A stylized grass field with controllable wind, built in Godot 4.7 by an agent
driving [godot-mcp](https://github.com/regiellis/godot-mcp-go).

Run it:

```bash
godot --path .
```

Fly the camera with `WASD`, `Q`/`E` for down and up, right mouse to look, and
shift to move faster. The panel retunes the grass, the wind, and the post stack
live, and the Field tab rebuilds the meadow at a new density on the spot.

## What it shows

- **250,000 blades** as a MultiMesh scatter: parent points with clumped
  children, over a 70 m field, built at load from a seed rather than stored.
  Nothing here is baked, so the scene file stays small and the field is
  reproducible from `seed_value` alone.
- A toon grass shader that takes its normal from the terrain below each blade,
  so the field shades as one carpet following the hills instead of as a million
  separate blades.
- A gust field scrolling across the meadow with per-blade flutter riding on top,
  weighted so roots stay planted and tips do not stretch.
- Procedural trees, generated in script from a seed. No mesh files.
- The soil, the blades, and the trees share one toon step, so they read as a
  single illustrated surface.

## Credits and licence

The grass technique is adapted from a Blender node tutorial,
<https://www.youtube.com/watch?v=HO9qdDPBuAo>, and reimplemented as a Godot
shader. The wind system is original: the tutorial had none.

Everything here is part of this project and carries its own licence. The trees
are generated by `trees/stylized_tree.gd` rather than imported, so the sample
ships no third-party art.
